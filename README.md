## Description
This project analyzes the relationship between torque and speed of a DC motor using Python.

## Inputs
- Voltage (V)
- Resistance (Ra)
- Motor constant (k)

## Outputs
- Speed values
- Torque vs Speed graph

## How to Run
1. Install C compiler (GCC)
2. Compile the program: gcc dc_motor.c -o motor
3. Run: ./motor
